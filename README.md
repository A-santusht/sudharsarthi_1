## 🚀 Free 1-Click Online Deployment

### Option 1: Deploy Frontend on Vercel (100% Free Forever)
1. Click the **[Deploy with Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FA-santusht%2Fsudharsarthi_1&project-name=sudharsarthi&root-directory=sudharsarthi/frontend)** button above.
2. Sign in with your GitHub account.
3. Click **Create** / **Deploy**. Vercel will build and assign you a free `https://<your-project>.vercel.app` live URL in under 30 seconds!

### Option 2: Deploy Full App (Flask Backend + Frontend) on Render (100% Free)
1. Click the **[Deploy to Render](https://render.com/deploy?repo=https://github.com/A-santusht/sudharsarthi_1)** button above.
2. Connect your GitHub account.
3. Render automatically picks up `render.yaml` and starts your Gunicorn Python backend with static frontend hosting!

## ✨ Features
- **Duhai GIS Radar**: Geographically constrained monitoring boundary for Duhai, Ghaziabad (RRTS station, depot, NH-34).
- **Interactive Deep Zoom**: 18.5× magnification controls on the map and per-issue zoom.
- **Dynamic Color-Changing Hover Bars**: Top map bar and urgency meter bars change colors with animated gradients on hover and auto-pop up telemetry cards.
- **Automatic Email Alerting**: Every registered report is instantly emailed with GPS coordinates, photos, and AI risk scores to `awasthishailendra59@gmail.com`.
- **⛏️ Minecraft Retro UI Mode**: Toggle retro craft mode (hotkey `M`), featuring an authentic 9-slot hotbar (keys `1`–`9`), Level 42 EXP bar, Web Audio sound effects, and pixel styling.
